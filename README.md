# krate docs

Documentation for [krate](https://krate.sh), a secure, container-compatible
runtime and governance platform. Every workload runs in its own microVM with its
own kernel, under policy enforced by the daemon.

krate is in beta and currently runs on macOS on Apple Silicon.

## Start here

- [Getting started](getting-started.md): install, log in, run a workload, and
  bring your own project.

`krate <command> --help` works on every command and is the most current
reference, since it comes from the binary you have installed.
